**The World in One Day — Wednesday 18 November**

A newspaper front page that sums up the world's news of Wednesday, 18 November 2026, in one image. The program (`main.ts`, Node 22, standard library only) draws the page entirely in code — raw RGB buffer, hand-written bitmap font, hand-written PNG encoder — and writes one deterministic 1024×1024 PNG to `/output/entry.png`.

Stories: the Kerch bridge struck again; the tanker aftermath off Hormuz (MT Tara Gas, 21 of 24 Indians evacuated at Khasab); Trump lands in Manila for Quad talks; Cyclone Akvan nears the Indian coast; Iran hits a US radar in Bahrain; Canada and China extend trade deals; and MS Dhoni bows out of IPL play as India win a record 10th SAFF Championship.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
